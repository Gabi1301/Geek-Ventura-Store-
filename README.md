# Geek-Ventura-Store-
Geek Ventura Store é um projeto de e-commerce desenvolvido para o segmento geek, reunindo produtos de Anime, Jogos, RPG, Eletrônicos e Música em uma plataforma moderna, responsiva e intuitiva.


*FOCO PRINCIPAL*
Usar tabelas de dados do Excel para criação de uma loja de e-commerce
